Got it — you’re building in React + TypeScript. The IBKR TWS API is not directly callable from the browser (it’s a raw TCP socket to localhost:7496/7497), so the standard pattern for a React TS app is:
	•	Node.js backend (or Electron main process) using a TypeScript-native TWS client like @stoqey/ib (full port of the official API).
	•	React frontend talks to the backend via REST or WebSocket (Socket.io, etc.).
If you’re using Electron, you can import @stoqey/ib directly in the renderer (with Node integration enabled).

export interface IbkrContract {

  symbol: string,
  exchange: 'NYSE' | 'NASDAQ' | 'AMEX' | 'ARCA' | 'BATS' = 'NYSE'

  exchange,
  currency: 'USD',
});

4. Discovery Script (find every IND breadth ticker your account can see)
Run this once in your Node backend — it will print all available breadth-style contracts (this is how people originally discovered the full set).
// src/ibkr/discoverBreadth.ts
import { IBApi, Contract, ErrorCode } from '@stoqey/ib';

const ib = new IBApi({
  host: '127.0.0.1',
  port: 7496,           // or 7497 for IB Gateway
  clientId: 999,
});

const prefixes = ['TICK', 'TRIN', 'AD', 'VOL', 'ADVANCE', 'DECLINE'];
const exchanges = ['NYSE', 'NASDAQ', 'AMEX', 'ARCA', 'BATS'];

ib.on('connected', () => {
  console.log('✅ Connected to TWS/IB Gateway');
  let reqId = 1000;

  exchanges.forEach((exch) => {
    prefixes.forEach((pre) => {
      const contract = new Contract();
      contract.symbol = pre;
      contract.secType = 'IND';
      contract.exchange = exch;
      contract.currency = 'USD';

      ib.reqContractDetails(reqId++, contract);
    });
  });
});

ib.on('contractDetails', (reqId: number, contractDetails: any) => {
  const c = contractDetails.contract;
  console.log(
    `${c.symbol.padEnd(15)} | ${c.exchange.padEnd(8)} | ${contractDetails.longName || '—'}`
  );
});

ib.on('contractDetailsEnd', (reqId: number) => {
  console.log(`✅ Finished reqId ${reqId}`);
});

ib.on('error', (err: Error, code: ErrorCode, reqId: number) => {
  console.error(`❌ Error ${code} (reqId ${reqId}):`, err.message);
});

ib.connect();
Run it with ts-node discoverBreadth.ts (or compile & run). It will give you the real, up-to-date list your TWS account can subscribe to — usually far fewer than 85, but everything that exists.
5. Requesting Market Data (example in backend)
const contract = createBreadthContract('TICK-NYSE', 'NYSE');

// Subscribe
ib.reqMktData(1001, contract as any, '', false, false, []);

// Handle ticks (last price for TICK/TRIN, bid/ask for AD/VOL)
ib.on('tickPrice', (reqId: number, tickType: number, price: number, attrib: any) => {
  console.log(`Req ${reqId} TickType ${tickType} = ${price}`);
});
