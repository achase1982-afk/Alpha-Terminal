## 5. Confidence Penalty for Cluster Disagreement

Add a new step after all clusters are scored but before final confidence is output. Check for cluster disagreement and penalize confidence:

```
// Cluster disagreement penalty
// Compare signs of each cluster score
const clusterScores = [ratesScore, creditScore, volLevelScore, volTermScore, breadthScore];
const positiveCount = clusterScores.filter(s => s > 0).length;
const negativeCount = clusterScores.filter(s => s < 0).length;

// If clusters disagree (some positive, some negative), penalize confidence
const disagreementPairs = Math.min(positiveCount, negativeCount);
const disagreementPenalty = disagreementPairs * 12; // 12 points per conflicting pair
confidence = Math.max(0, confidence - disagreementPenalty);
```

This ensures that when signals conflict (e.g. credit is bullish but breadth volume is bearish), the confidence score reflects that uncertainty rather than presenting a high-confidence call built on contradictory data.
