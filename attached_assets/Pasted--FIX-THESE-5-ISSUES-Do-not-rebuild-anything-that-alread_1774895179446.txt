## BUG 4: Options Strategist shows raw JSON on screen

When the Strategist generates results, raw JSON text (curly braces, quotes, property names) appears on screen before/instead of formatted strategy cards.

**Fix:** The backend stream handler is mixing thinking tokens and final response tokens into the same output. They must be completely separated:

```typescript
let responseBuffer = '';

for await (const part of result.fullStream) {
  if (part.type === 'reasoning' || part.type === 'thought') {
    // THINKING: send to frontend as thinking event
    res.write(`event: thinking\ndata: ${JSON.stringify({ text: part.textDelta || part.text })}\n\n`);
    if (typeof res.flush === 'function') res.flush();
  } else if (part.type === 'text-delta') {
    // FINAL RESPONSE: buffer silently, do NOT send to frontend yet
    responseBuffer += part.textDelta;
  }
}

// After stream completes: parse buffer as JSON, send as result event
try {
  const parsed = JSON.parse(responseBuffer);
  res.write(`event: result\ndata: ${JSON.stringify({ type: 'complete', data: parsed })}\n\n`);
} catch (e) {
  res.write(`event: error\ndata: ${JSON.stringify({ message: 'Failed to parse AI response' })}\n\n`);
}
res.end();
```

On the frontend, the SSE consumer must route events to different destinations:

- `event: thinking` data goes ONLY to the AI Thinking Feed component
- `event: result` data goes through JSON parsing and into the formatted UI components (strategy cards, dashboard, etc.)
- These two streams must NEVER cross
