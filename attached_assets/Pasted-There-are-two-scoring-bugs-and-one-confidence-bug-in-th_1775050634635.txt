There are two scoring bugs and one confidence bug in the deterministic Market Pulse engine that need to be fixed. Both scoring bugs are caused by the same root problem: the engine is trying to use percent change to score indicators that should be scored on their absolute values or on ratios between related indicators. The TOS data feed delivers correct raw values for all of these indicators but the percent change field is either missing or zero for breadth indicators because they are cumulative intraday readings that reset daily and are not price instruments. For vol term structure indicators the percent change may or may not be present depending on whether the market is open but even when present it is the wrong signal because what matters is the shape of the term structure curve not how much each individual vol index moved.

BUG 1 BREADTH CLUSTER. The five breadth indicators TICK, TRIN, ADD, ADVN, and DECN must never be scored using percent change. Remove any percent change logic from the breadth scoring function entirely. Replace it with the following absolute value scoring rules. TICK: above 200 scores +0.5, above 600 scores +1.0, above 1000 scores +2.0. Below negative 200 scores -0.5, below negative 600 scores -1.0, below negative 1000 scores -2.0. Between negative 200 and positive 200 scores 0. TRIN: below 0.8 scores +2.0 strongly bullish, between 0.8 and 1.0 scores +1.0 bullish, between 1.0 and 1.2 scores -1.0 bearish, above 1.2 scores -2.0 strongly bearish. Note that TRIN is inverted so low values are bullish. ADD: above 1000 scores +2.0, above 500 scores +1.0, above 0 scores +0.5, below 0 scores -0.5, below negative 500 scores -1.0, below negative 1000 scores -2.0. ADVN and DECN: do not score these individually. Compute the ratio ADVN divided by DECN. Ratio above 3.0 scores +2.0 strongly bullish, ratio above 2.0 scores +1.0 bullish, ratio between 0.5 and 2.0 scores 0 neutral, ratio below 0.5 scores -1.0 bearish, ratio below 0.33 scores -2.0 strongly bearish. The final breadth cluster score is the average of the four component scores which are TICK, TRIN, ADD, and the ADVN/DECN ratio. Clamp the result to the range negative 2.0 to positive 2.0.

BUG 2 VOL TERM STRUCTURE CLUSTER. VIX9D, VIX3M, and SKEW should not be scored using percent change. These must be scored using the mathematical relationships between them and the spot VIX value. Use the following rules. VIX9D vs VIX ratio: compute VIX9D divided by VIX. If the ratio is below 0.90 that means short term vol is collapsing relative to spot which is bullish, score +1.5. If the ratio is between 0.90 and 0.95 score +1.0 mildly bullish contango. If the ratio is between 0.95 and 1.05 score 0 neutral. If the ratio is between 1.05 and 1.10 score -1.0 mildly bearish backwardation. If the ratio is above 1.10 score -1.5 bearish backwardation meaning near term fear is elevated. VIX vs VIX3M ratio: compute VIX divided by VIX3M. If the ratio is below 0.85 score +1.5 steep contango is bullish. If between 0.85 and 0.95 score +1.0. If between 0.95 and 1.05 score 0 flat. If between 1.05 and 1.15 score -1.0 mild backwardation. If above 1.15 score -1.5 steep backwardation is bearish. SKEW: above 150 scores -1.0 as elevated tail risk hedging is mildly bearish. Between 130 and 150 scores 0 normal. Between 110 and 130 scores +0.5 low tail hedging is mildly bullish. Below 110 scores +1.0. The final vol term structure cluster score is the average of these three component scores clamped to negative 2.0 to positive 2.0.

BUG 3 CONFIDENCE FLOOR. The confidence calculation currently allows penalty multipliers to stack and multiply each other down to near zero which is why the engine is outputting 0 percent confidence even when the composite is nonzero. Add a floor so that the combined penalty multiplier can never go below 0.3. This means even in a worst case scenario with multiple penalties active the confidence will be at least 30 percent of what the raw composite would produce. Also lower the NO_EDGE composite threshold from 0.40 to 0.30 so that a composite of 0.30 or above can produce a directional bias if the confidence supports it.

Do not change anything about how the other clusters work including rates, credit, vol level, risk appetite, and macro. Only fix breadth, vol term structure, and the confidence floor. After making these changes run a test with the current market data to verify the breadth and vol term structure clusters are producing nonzero scores. For reference with the current data the breadth cluster should score approximately positive 1.6 based on TICK 263 scoring +0.5 and TRIN 0.83 scoring +2.0 and ADD 1471 scoring +2.0 and ADVN/DECN ratio of 3.44 scoring +2.0 for an average of about 1.625.
