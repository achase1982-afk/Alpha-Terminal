Role: Senior React/FinTech Developer.
Objective: We are adding a live Market News feed to the terminal as a dedicated tab. It will use the Finnhub API to fetch news dynamically based on the currently active ticker symbol.

Task 1: Update the Navigation Bar.
- Locate the main navigation menu containing the tabs: `CHART`, `OPTIONS`, `AI`, and `SCAN`.
- Insert a new tab called `NEWS` into this menu (e.g., between CHART and OPTIONS, or wherever it fits best visually).
- Add a relevant icon for the NEWS tab (e.g., a Newspaper or Globe icon from lucide-react).

Task 2: The Finnhub Data Layer.
- Create a data fetching hook (e.g., `useTickerNews`) that triggers when the `NEWS` tab is active.
- Fetch from the Finnhub Company News endpoint: `https://finnhub.io/api/v1/company-news?symbol={activeTicker}&from={oneWeekAgoDate}&to={todayDate}&token={process.env.FINNHUB_API_KEY}`.
- Ensure the API key is pulled securely from the environment variables (`FINNHUB_API_KEY`).
- Handle loading states and empty states (e.g., "No news available for this ticker").

Task 3: Build the `NewsTab` Component.
- Create the UI component that renders when the `NEWS` tab is selected. It should take up the remaining vertical space with `overflow-y-auto`.
- Map through the news articles. For each article, display:
  1. The Source (e.g., Bloomberg, Reuters) in a muted accent color (`text-amber-500 text-[10px] uppercase tracking-wider`).
  2. The Headline (`text-sm font-semibold text-zinc-200 mt-1`).
  3. The 'Time Ago' (e.g., "2h ago") converted from the Unix timestamp (`text-zinc-500 text-xs`).
  4. A brief snippet/summary if provided by the API (`text-xs text-zinc-400 mt-1 line-clamp-2`).
- Make the entire article card clickable, opening the source URL in a new tab (`target="_blank" rel="noopener noreferrer"`).

Task 4: Terminal Aesthetics.
- Keep the design dense and terminal-grade. Use a dark theme matching the rest of the app.
- Separate each news item with a clean bottom border (`border-b border-zinc-800/50 pb-4 mb-4`).
- Add a subtle hover effect (`hover:bg-zinc-800/30 p-2 rounded-md transition-colors`) so the user knows the row is clickable.
