==== PART 1: FLAT FILES DATA INTEGRATION ====

1.1 Build a trailing baseline query helper that reads polygon_options_history and returns:
- 20-day average daily options volume per contract
- 20-day average daily options notional per ticker
- 20-day average vol/OI ratio per contract
- Accepts ticker, lookback days, optional contract filter

1.2 Add "intraday volume breakout" detection to the unusual flow detector. Fires when a contract's volume today >= 3x its 20-day trailing average, minimum 200 contracts today.

1.3 Add "flow acceleration" scoring input to the deterministic scanner's Flow bucket. Compares recent 3-day options activity vs trailing 20-day baseline. Scoring: recent 3-day > 2x trailing = full credit, > 1.5x = partial. Propose exact point mapping.

1.4 Add a "trailing unusual flow" query and API endpoint surfacing tickers with unusual activity in the last 5 trading days, including tickers not in any current watchlist. API only, no UI yet.

1.5 Graceful degradation: if polygon_options_history has less than 10 days of history for a ticker, new baselines return null/zero and existing Flow bucket falls back to current behavior. No crashes on sparse data.

==== PART 2: BACKGROUND WATCHER (PERSISTENT LIVE TAPE) ====

2.1 Build a background watcher process that opens a single persistent Polygon WebSocket connection on market open and holds it through market close.

2.2 Default coverage universe: LC130 plus an optional mid-cap watchlist (up to 30 tickers). Per-ticker baseline: nearest 2 expirations, ±7% strikes, calls and puts. Target ~780-960 contracts under the 1,000 cap.

2.3 Three-tier detection pipeline running continuously:
- Tier 1 (always-on): baseline coverage above, fires sweeps, blocks, vol/OI spikes, and new intraday volume breakout from Part 1 into a rolling session log
- Tier 2 (reactive widening): when Tier 1 detects unusual activity on a ticker, auto-subscribe to wider ±15% OTM range and nearest 3 expirations on that ticker for 30-60 min. Borrows from headroom budget. Releases automatically.
- Tier 3 (manual drill-down): when user clicks into a specific ticker in UI, "deepen coverage" button temporarily subscribes ±25% strikes, out to 90 DTE on that ticker. Holds until user closes view.

2.4 Rolling session log persists all detections for the full trading session (market open to close), not a 30-minute rolling window.

2.5 Watchlist-aware: user can swap the watcher's universe between LC130, LC130+midcap, or other watchlists. Re-subscribes on switch.

2.6 Detection math, all deterministic and documented with comment blocks:
- Sweep: same contract, 3+ prints across 2+ exchanges within 500ms, total size >= 100 contracts
- Block: single print >= 500 contracts OR >= 10% of contract OI
- Vol/OI spike: vol/OI >= 3.0 AND volume >= 500 AND OI >= 10
- Intraday volume breakout: today's volume >= 3x 20-day trailing average, minimum 200 contracts (from Part 1)
- Aggressor side: price >= ask = BULLISH for calls / BEARISH for puts, price <= bid = opposite, between = NEUTRAL

2.7 Reuse patterns from the Schwab streamer reconnect fix: closure-captured socket identity with isCurrent gating, 20s keepalive ping with 45s pong watchdog, 15s handshake and 10s auth timeouts, auth-gated backoff reset, credential refresh after 3 consecutive failures.

2.8 Env gate: POLYGON_OPTIONS_WS_ENABLED stays false by default. I will flip it to true manually for the first live smoke test during market hours after review.

3.4 Events accumulate in the same session log as the background watcher, tagged by the watchlist that was scanned.

3.5 Subscription releases when user closes the scan or switches watchlists.
