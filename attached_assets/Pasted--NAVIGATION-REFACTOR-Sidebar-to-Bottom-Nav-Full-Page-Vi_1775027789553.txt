## PART 1: BOTTOM NAVIGATION BAR

### Component: `BottomNav.tsx`

A persistent bottom bar that sits at the very bottom of the screen, BELOW all content. It never scrolls away.

**5 items:**

```
[ SCANNER ]  [ MARKETS ]  [ ⚡ AI ]  [ PORTFOLIO ]  [ WATCHLIST ]
```

**Behavior:**

- SCANNER: Switches the main top tab to “scanner” (same as tapping SCAN in the top tabs)
- MARKETS: Opens a full-page Markets view (market overview, indices, sectors – this is a NEW page, can be a placeholder for now)
- ⚡ AI (center button): Opens the AI Chat overlay (same as the current AI SEARCH button in the sidebar)
- PORTFOLIO: Opens a full-page Portfolio view (NEW page, placeholder for now showing “Portfolio coming soon”)
- WATCHLIST: Opens a full-page Watchlist view showing the user’s watched symbols with price data

**Styling:**

```
Container:
  - Fixed to bottom of screen
  - height: 56px (standard mobile nav height)
  - bg-[#0c0c0c] (match sidebar background)
  - border-t border-card-border
  - z-index: 50 (above all content)
  - safe-area-inset-bottom padding for iPhone notch/home indicator:
    padding-bottom: env(safe-area-inset-bottom, 0px)

Each nav item:
  - flex-1, flex-col, items-center, justify-center
  - gap-0.5
  - Icon: 20px, muted-foreground when inactive, primary (#FFB800) when active
  - Label: font-mono, text-[9px], uppercase, tracking-wider
  - Active state: text-primary, icon text-primary
  - Tap feedback: opacity-70 on press

Center AI button (special):
  - Larger icon area: w-12 h-12 rounded-full
  - bg-primary/10, border border-primary/30
  - The lightning bolt icon centered inside
  - Slightly elevated: -mt-3 to pop above the nav bar
  - Glow effect on active: box-shadow 0 0 12px primary/30
```

**Important:** The bottom nav must account for the iPhone home indicator bar. Add:

```css
.bottom-nav {
  padding-bottom: max(env(safe-area-inset-bottom, 0px), 8px);
}
```

Also, the main content area needs bottom padding so content doesn’t hide behind the bottom nav:

```css
.app-content {
  padding-bottom: calc(56px + env(safe-area-inset-bottom, 0px));
}
```

### State Management

Add a `bottomNavRoute` state to track which bottom nav item is active. When a bottom nav item is tapped:

- **SCANNER:** Set `activeMainTab` to “scanner” (reuses existing tab system). Bottom nav highlights SCANNER.
- **MARKETS:** Set `bottomNavRoute` to “markets”. Renders MarketsPage as a full-screen view OVER the main content.
- **⚡ AI:** Opens `chatOpen` state (already exists for AiChatOverlay). No route change.
- **PORTFOLIO:** Set `bottomNavRoute` to “portfolio”. Renders PortfolioPage as a full-screen view.
- **WATCHLIST:** Set `bottomNavRoute` to “watchlist”. Renders WatchlistPage as a full-screen view.

When a full-page view is open (markets, portfolio, watchlist), the main terminal content is hidden behind it. The full-page view has its own back/close button in its header.

## PART 2: FULL-PAGE VIEWS

### Architecture

Full-page views render on top of the main terminal content. They have:

- A header bar with title + close/back button
- Scrollable content area
- The bottom nav remains visible at the bottom

```tsx
interface FullPageViewProps {
  title: string;
  onClose: () => void;
  children: React.ReactNode;
}

function FullPageView({ title, onClose, children }: FullPageViewProps) {
  return (
    <div className="fixed inset-0 z-40 bg-background flex flex-col" style={{ paddingBottom: 'calc(56px + env(safe-area-inset-bottom, 0px))' }}>
      <header className="shrink-0 flex items-center h-12 px-4 border-b border-card-border bg-card">
        <button onClick={onClose} className="p-2 rounded-lg text-muted-foreground hover:text-foreground">
          <ArrowLeft className="w-5 h-5" />
        </button>
        <h2 className="font-mono text-sm font-bold tracking-wider text-foreground ml-3">{title}</h2>
      </header>
      <div className="flex-1 overflow-y-auto">
        {children}
      </div>
    </div>
  );
}
```
