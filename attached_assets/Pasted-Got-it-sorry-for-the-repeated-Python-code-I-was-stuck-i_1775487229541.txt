The core problem you’re seeing (extreme delay + glitchy updates, despite Replit saying “every 1 second”) is not Schwab’s WebSocket. Schwab pushes updates in real time (often 10–50+ times per second on liquid stocks like MRVL — exactly the flickering you saw in the video). Replit’s dev preview / reverse proxy is notorious for buffering, throttling, and adding 500–2000 ms+ latency to long-lived WebSockets. The “1-second fetch” suggestion was them accidentally turning your true push stream into slow polling.
Best fix for React + TypeScript
Use the excellent unofficial but very well-maintained TypeScript library made specifically for Schwab/TD Ameritrade streaming in the browser:
@allensarkisyan/schwab-td-ameritrade-streamer
It handles login, subscriptions, and real-time events cleanly with zero manual JSON wrangling.

2. Real-time React hook example (LEVELONE_EQUITIES)
'use client'; // or remove if not Next.js

import { useEffect, useState, useRef } from 'react';
import { createTDAmeritradeStreamer, TDAmeritradeStreamer } from '@allensarkisyan/schwab-td-ameritrade-streamer';

interface LevelOneQuote {
  symbol: string;
  lastPrice: number;
  lastPriceTime?: number;
  bidPrice?: number;
  askPrice?: number;
  volume?: number;
  // add any other fields you need from the stream
}

export const useSchwabMarketData = (accessToken: string, accountId: string) => {
  const [quotes, setQuotes] = useState>(new Map());
  const streamerRef = useRef(null);

  useEffect(() => {
    let streamer: TDAmeritradeStreamer;

    const initialize = async () => {
      // Step A: Fetch user principals (REST call you probably already make)
      const principalsResponse = await fetch('https://api.schwab.com/trader/v1/userPrincipals', {
        headers: { Authorization: `Bearer ${accessToken}` },
      });
      const principals = await principalsResponse.json();

      // Step B: Create the streamer (browser-native WebSocket under the hood)
      streamer = createTDAmeritradeStreamer({
        streamerConnectionOptions: {
          streamerSocketUrl: principals.streamerSocketUrl,
          token: principals.token,           // streaming token from principals
          accountId,
          credential: accessToken,
        },
      });

      streamerRef.current = streamer;

      // Subscribe to real-time Level 1 quotes (this gives you the flickering updates)
      await streamer.subscribeLevelOneEquities(['MRVL']);   // add more symbols as needed

      // Listen for updates (fires instantly on every trade/quote change)
      streamer.on('LEVELONE_EQUITIES', (data: any) => {
        setQuotes(prev => {
          const newMap = new Map(prev);
          data.forEach((quote: any) => {
            newMap.set(quote.symbol, {
              symbol: quote.symbol,
              lastPrice: quote.lastPrice,
              bidPrice: quote.bidPrice,
              askPrice: quote.askPrice,
              volume: quote.volume,
              // ...map whatever fields you want
            });
          });
          return newMap;
        });
      });

      // Optional: also subscribe to account activity if you need order/position flow
      // streamer.subscribeAccountActivity();
    };

    initialize().catch(console.error);

    // Cleanup on unmount
    return () => {
      if (streamerRef.current) {
        streamerRef.current.close();
      }
    };
  }, [accessToken, accountId]);

  return { quotes, streamer: streamerRef.current };
};
