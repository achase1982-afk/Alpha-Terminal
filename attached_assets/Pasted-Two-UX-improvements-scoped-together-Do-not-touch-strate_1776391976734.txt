- Market Pulse

The existing icons on these items are fine, keep them.

Visual grouping in the sidebar: insert a section divider between "Linked Brokerage" and "Market Pulse" with the section label "ANALYSIS" (small uppercase gray text). Another divider between "Options Strategist" and "Settings".

The AI chat box and Logout stay at the bottom of the sidebar, unchanged.

CHANGE 2: TELEMETRY UNIFICATION AND UX CLEANUP

Current state: Two separate telemetry panels exist (general Telemetry and Strategist Telemetry). The general panel is dense, dominated by transient WebSocket reconnect events, and not visually prioritized. Users cannot easily see what actually needs attention vs what auto-recovered.

Target state: One unified Telemetry screen with two tabs, with automatic noise filtering and severity prioritization.

Unified structure: replace both existing telemetry entries with a single "Telemetry" item under Settings > System. This screen has two tabs at the top:

- EVENTS (what's currently in general Telemetry - Schwab stream, API events, scanner errors, etc.)
- TRADES (what's currently in Strategist Telemetry - recommendations, scanner runs)

The existing functionality within each tab is preserved. This is about unifying the entry point and improving the UX of the Events tab specifically.

UX improvements to the Events tab:

1. System health summary at the top. A single line showing status of each monitored system. Format example:
   "Schwab API: Connected | Schwab Stream: Active | IBKR: Connected | Scanner: Active | Strategist: Active"
   Each status uses color: green for healthy, yellow for degraded, red for error. If any system is red, it appears first in the list.

2. Action Needed section. Below the health summary, show a sticky section titled "ACTION NEEDED" that contains any unresolved ERROR-level events. Each entry shows:
   - Error title (e.g., "Polygon 403: Universe build failed")
   - One-line explanation of what it means
   - One or two suggested actions (e.g., "Upgrade Polygon plan" link, "Dismiss" button)
   
   If there are no unresolved errors, this section shows a single line: "No action needed" with a green check.

3. Auto-resolve paired events. When a disconnect event is followed by a successful reconnect within 30 seconds, collapse both into a single entry labeled "Auto-recovered: [system] briefly disconnected [time]" and move it out of the main visible list into the recent activity section. If more than 5 auto-recovered events occur within a 5-minute window, collapse them further into "System [X] auto-recovered [N] times in last [T] minutes - possible instability."

4. Severity-first ordering. Within the event list, order by severity (ERROR first, then WARN, then INFO) rather than by time. Within same severity, order by most recent first.

5. Larger font on event titles. Current text is too small to scan. Event title should be 15-16px, metadata 12px. Increase line height for readability.

6. Resolved filter. Add "Unresolved" as the default filter at the top, alongside the existing ALL/ERROR/WARN/INFO tabs. User can toggle to see resolved history. Resolved means either auto-recovered or manually dismissed.

7. Bulk resolve. Add a "Resolve all auto-recovered" button in the header when there are 10+ auto-recovered events. Clears them from the unresolved view.

8. Keep the existing drawer/dropdown for filtering by system (SCHWAB API, SCHWAB STREAM, etc.). That UI is fine.

The Trades tab (current Strategist Telemetry) keeps its existing UI and functionality. No changes to that tab in this pass.
