Generated by Playwright against the **real** Vite dev server (`/qa` harness + mocked `/api` + WS).

```bash
# After (PR B branch)
QA_SNAPSHOT_VARIANT=after pnpm --filter @workspace/alpha-terminal run test:e2e:qa-screenshots

# Before (main UI on OrderTicket + OptionsTab, same harness/mocks)
pnpm --filter @workspace/alpha-terminal run test:e2e:qa-screenshots:before
```

| `option-close` | both | Close ticket |

The `/qa` harness is **dev-only** (`import.meta.env.DEV` && `VITE_QA_HARNESS=true`), lazy-loaded, and omitted from production builds.
